# Garden of Eden — the chosen storyline

**This is the story.** It outgrew this folder: the full treatment — the
world, the threads, the systems, the endings — is
[../direction/](README.md). This file states the premise and
holds the two ideas that belong to the storyline rather than to any one
space.

## The premise

The player is a pattern in a cellular automaton that became something the
rules do not account for.

A **Garden of Eden** is a configuration with no possible predecessor: a
state the automaton can be in, but can never have arrived at. It is not a
metaphor. It is a defined object with a theorem attached, and the theorem
is what the game is about — in an *amenable* world, anything that exists
can be accounted for backwards; in a *non-amenable* one, it cannot. So a
pattern with no past is impossible in the flat, closed spaces where the
game begins, and possible in the negatively-curved ones it ends in.

The player walks that scale from one end to the other. What looks like a
journey through geometries is a search for somewhere they are allowed to
have come from nowhere.

See [../direction/mathematics.md](mathematics.md) for the
theorem, and [../direction/README.md](README.md) for what the
game makes of it.

## Evolution as progression

The automaton's own taxonomy is a ladder, and each rung is something the
player can do:

| Rung | What it is | What it grants |
|---|---|---|
| Still life | a pattern that persists unchanged | existing at all — walking |
| Oscillator | returns to itself on a period | acting on the world's tick |
| Glider | translates as it cycles | traversal |
| Spaceship | a faster traveller | speed |
| Gun | emits patterns | scouting — sending something ahead |
| Garden of Eden | has no predecessor | the ending |

The ladder is **not** climbed by playing as each form. That was tried and
cut: controlling a glider is worse than walking in every respect, and
switching bodies turned out to be the wrong verb entirely. What survives
is the ladder as *subject matter* — the player is already far past the
primitives, and spends the game learning to read the things they are made
of. See [../direction/systems.md](systems.md).

## Perception as a rung

Start colourblind. Gain colour later.

This is a perception unlock rather than a movement one, and its value is
that it is **retroactive**: every biome already visited had paths the
player's own eye could not resolve, and gaining the rung re-reads all of
them at once. That is a stronger fit for "interconnected, not a level
select" than any per-biome perception rule can be, because it changes
places the player is not currently standing in.

Diegetically it is not a lens bolted on for a puzzle: an early generation
genuinely has no colour rule running yet. Perceiving colour is something a
pattern had to evolve, the same as anything else on the ladder.

**Open:** which rung colour attaches to, which built biome gets the first
retroactive reread, and whether colourblindness is a real rendering
constraint or a fictional frame around an existing perception rule.

## The glider stage, made literal

The Fold's geodesic sphere already *is* this rung, mechanically: twelve
pentagon sockets on a hex tiling, a live automaton, and a maze whose walls
answer to it.

Composing a pattern at a socket and watching whether it stabilises into a
genuine traveller is the same test the taxonomy runs on the player one
rung up. Solving the maze by letting gliders open walls at the right place
and time — or by riding one over a wall walking cannot cross — is the rung
teaching itself. The player does not merely *become* a glider in the
fiction; they first have to *build* one, on a board they can see is the
same taxonomy they are climbing.

## What the premise costs

Recorded because it was real and remains real: this fiction does not
survive on stone, grass and forest. It wants a rendering language that
reads as *substrate* rather than as landscape, and it invites expectations
of cellular and generative visuals — a larger rendering commitment than a
painterly world would have been. The art direction that answers this is
[../direction/art-and-audio.md](art-and-audio.md).
